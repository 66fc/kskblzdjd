## 2. 部署架构

```
组员浏览器
   │  HTTPS
   ▼
Cloudflare 隧道  ──►  node scripts/serve-prod.mjs  (0.0.0.0:8088)
                          │   ├─ 托管 frontend/dist（Vue 3 生产构建）
                          │   └─ 反向代理 /api  ──►  Spring Boot (127.0.0.1:8080)
                                                         │
                                                         ▼
                                                   MySQL 8.0 (127.0.0.1:3307)
```

只对外暴露 **8088 一个端口**：前端静态资源与 API 同源，浏览器不会遇到跨域问题；后端和数据库仍只监听本机，不直接暴露到公网。

## 3. 启动与停止

### 一键启动（生产模式）

```bat
scripts\start-prod.bat
```

脚本依次完成：

1. 检查并启动 MySQL（3307）
2. 检查并启动 Spring Boot（8080），未打包时提示先打包
3. 检查并启动静态服务（8088）
4. 打印本机、局域网地址与服务健康状态

### 开启公网链接

```bat
scripts\start-tunnel.bat
```

自动启动 cloudflared 并解析出 `https://xxx.trycloudflare.com` 地址。关闭标题为 `Tunnel` 的窗口即断开。

### 开放局域网访问（只需做一次）

当前这台机器所在 WiFi 被 Windows 判为「公用网络」，默认拦截入站连接，因此**其他电脑访问局域网地址会失败**。执行一次即可：

```bat
scripts\allow-lan-firewall.bat
```

> 需要右键「以管理员身份运行」，脚本会自提权并添加 8088 端口入站规则。
> 如果仍不通，把网络类型从「公用」改为「专用」：设置 → 网络和 Internet → WLAN → 属性 → 网络配置文件。

### 停止服务

- 关闭对应的 `Backend` / `Web` / `Tunnel` / `MySQL` 命令行窗口即可
- 仅停 MySQL：`scripts\stop-mysql.bat`

## 4. 组员怎么用

### 体验预约（真实写库）

1. 打开公网地址 → 右上角「登录 / 注册」
2. 点「立即注册」，填用户名、昵称、手机号、密码 → 自动登录
3. 进入「场地预约」，选日期（可点日历选未来任意日期）、开始时间、时长
4. 选一块空闲场地 → 确认预约 → 填写确认后生成正式订单（**真实入库并占用场地时间段**）
5. 「我的预约」可查看、取消（取消需填原因，取消后该时段立即恢复可预约）

### 体验后台

用 `admin / admin123` 在 `/login` 登录，可以：

- 数据总览、场地管理、用户管理、会员等级调整
- 预约管理（签到、结束使用、取消）
- 销售管理、日使用统计（真实调用存储过程）
- **模拟时间控制**：修改模拟日期后，客户端刷新即同步

## 5. 多人同时访问的说明

- 数据全部落在真实 MySQL，**多人操作互不覆盖**，但会互相影响同一批演示数据
- 预约冲突由后端事务 + `SELECT ... FOR UPDATE` + 数据库触发器保证，不会出现同一时段双卖
- 如果演示数据被改乱，一条命令还原：

```bat
scripts\init-db.bat
```

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 页面能开但列表空、提示后端未启动 | Spring Boot 没起来 | 看 `Backend` 窗口日志，重跑 `start-prod.bat` |
| 公网地址打不开 | 隧道已断 / 本机休眠 | 重跑 `start-tunnel.bat`，保持本机开机联网 |
| 组员打不开局域网地址 | 防火墙拦截（公用网络） | 管理员运行 `scripts\allow-lan-firewall.bat` |
| 登录提示 403 | 后端 CORS 未放行来源 | 生产 jar 已支持 `CORS_ORIGIN_PATTERNS`，默认放开；改配置后需重新打包 |
| 显示的时间不是当前真实时间 | 模拟时钟处于 SIMULATED 模式 | 后台「模拟时间」页面切回真实时间或调整模拟时间 |
| 预约提示时段冲突 | 该时段已被占用（正常业务拦截） | 换时间段，或先取消自己的订单 |

## 7. 安全与生产化提醒

当前是**课程演示部署**，公开给组员访问时请注意：

1. `CORS_ORIGIN_PATTERNS` 默认 `*`（回显来源），便于隧道/局域网访问。正式上线应设为固定域名：
   ```bat
   set CORS_ORIGIN_PATTERNS=https://your-domain.com
   ```
2. JWT 密钥、数据库密码仍是演示值，位于 `application.yml` 与 `scripts\env.bat`，正式环境须改为环境变量注入。
3. 公网隧道为临时域名，且流量经过 Cloudflare 免费通道，**不适合承载真实业务数据**。
4. 删除测试账号、重置演示数据用 `scripts\init-db.bat`。
